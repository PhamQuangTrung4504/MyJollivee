# Trung & Vy - Thiệp tình yêu

Trang web tĩnh một trang, tối ưu cho desktop, tablet và mobile.

## Cấu trúc

- `index.html` - khung nội dung chính
- `styles.css` - giao diện và hiệu ứng cuộn
- `app.js` - render dữ liệu, modal xem ảnh/video, hiệu ứng trái tim
- `assets/image/` - ảnh JPG
- `assets/video/` - video MP4
- `assets/sound/` - âm thanh MP3
